# Scores used in the editor walkthrough

| File | What it is | Rights |
| --- | --- | --- |
| `faure-op121.mxl` | Gabriel Fauré, String Quartet Op. 121. From [OpenScore String Quartets](https://github.com/OpenScore/StringQuartets) (`scores/Fauré,_Gabriel/String_Quartet,_Op.121/sq7358708.mxl`), unmodified. | CC0 |
| `ode-to-joy.musicxml` | The Ode to Joy theme from Beethoven's Ninth Symphony, eight bars for violin. | The music is in the public domain; the file was made for this walkthrough. |
| `ode-phrase.musicxml` | The first four bars of the same, followed by four empty bars. | As above. |

The two Ode to Joy files were made in the editor itself, the way the `note-entry` scene shows
(New Score, then note input from the keyboard), and saved with File ▸ Export ▸ MusicXML. To remake
one, do the same by hand; they are small enough to check by eye.

Only CC0 and public-domain music is used, so the finished video can be published anywhere.
